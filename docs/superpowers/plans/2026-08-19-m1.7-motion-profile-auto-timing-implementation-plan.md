**Goal:** Replace hand-authored free-space/carry `duration_s` authority with backend-neutral kinematic limits, motion-profile scaling, minimum-jerk automatic timing, and structured joint-rate evidence while preserving the frozen M1.6 grasp/lift physics and task semantics.

**Tech Stack:** Python 3.10+, stdlib `dataclasses`/`math`/`typing`, NumPy where already required, PyYAML, pytest, existing Isaac Sim backend for final Golden execution. No new runtime dependency is introduced in M1.7-A.

import math

from .limits import ResolvedJointKinematicLimits

_MIN_JERK_PEAK_V = 1.875
_MIN_JERK_PEAK_A = 5.773502691896257
_MIN_JERK_PEAK_J = 60.0

@dataclass(frozen=True)
class ScalarTimingResult:
    duration_s: float
    limiting_constraint: str

@dataclass(frozen=True)
class JointTimingResult:
    duration_s: float
    limiting_joint: str
    limiting_constraint: str


def minimum_jerk_duration(
    displacement: float,
    *,
    max_velocity: float,
    max_acceleration: float,
    max_jerk: float,
    minimum_duration_s: float = 0.0,
) -> ScalarTimingResult:
    d = abs(float(displacement))
    v = float(max_velocity)
    a = float(max_acceleration)
    j = float(max_jerk)
    floor = float(minimum_duration_s)
    if not all(math.isfinite(x) for x in (d, v, a, j, floor)) or v <= 0.0 or a <= 0.0 or j <= 0.0 or floor < 0.0:
        raise ValueError("MOTION_TIMING_INPUT_INVALID")

        ("velocity", _MIN_JERK_PEAK_V * d / v),

- [ ] **Step 3: Implement immutable evidence and stateful audit**

Public shape:

```python
@dataclass(frozen=True)
class JointRateEvidence:
    joint_name: str
    peak_velocity_rad_s: float
    peak_acceleration_rad_s2: float
    max_velocity_utilization: float
    max_acceleration_utilization: float

@dataclass(frozen=True)
class JointRateAuditSummary:
    per_joint: tuple[JointRateEvidence, ...]
    max_velocity_utilization: float
    max_acceleration_utilization: float
    classification: str

class JointRateAudit:
    def __init__(self, limits: ResolvedJointKinematicLimits) -> None: ...

    def observe(self, *, time_s: float, command: JointPositionCommand) -> None: ...

    def summary(self) -> JointRateAuditSummary: ...
```

Finite differences:

```text
qdot[k]  = (q[k] - q[k-1]) / dt
qddot[k] = (qdot[k] - qdot[k-1]) / dt
```

Classification:

```text
max velocity utilization <= 1 and max acceleration utilization <= 1
→ MOTION_LIMIT_AUDIT_PASS

otherwise
→ MOTION_LIMIT_AUDIT_REVIEW_REQUIRED
```

Do not compute finite-difference jerk as formal evidence in M1.7-A.

Structural invalidity raises deterministic `ValueError` and is allowed to make the outer Golden runner BLOCK.
